주의할 점

LED 극성

긴 다리(+, 애노드)를 220Ω 쪽에, 짧은 다리(−, 캐소드)를 GND에. 거꾸로면 안 켜지지만 망가지진 않아요.

밝기는 코드에서 PWM으로 조절할 수 있고, 최대 밝기는 220Ω이 정합니다.

콘덴서 두 개

100nF는 슬라이더 가운데 핀(029)과 GND 사이, 보드 쪽에 가깝게. 전선이 주워 담은 노이즈까지 걸러줍니다. 극성 없음.

10µF는 VCC와 GND 사이, LED·슬라이더가 있는 기판 쪽에. LED가 켜질 때 3.3V가 출렁이는 걸 잡아요. 전해면 긴 다리(+)가 VCC, 흰 띠 쪽이 GND.

버튼 (마이크로 스위치)

극성 없음. 단자 COM을 핀에, NO를 GND에. 3단자(SPDT)면 NC는 비워 둠 — 거꾸로 NC를 쓰면 안 누를 때 눌린 걸로 인식돼요. 풀업은 칩 내부 것을 쓰므로 외부 저항이 필요 없어요.

단자 이름이 안 찍혀 있으면 멀티미터 통전으로: 안 누른 상태에서 서로 통하는 두 단자가 COM–NC, 누르면 통하는 쌍이 COM–NO.

RST 스위치

RST 핀과 GND 사이에 작은 택트 스위치 하나. 한 번 누르면 재부팅, 두 번 빠르게 누르면 부트로더 모드(NICENANO 드라이브가 뜸)로 들어가 펌웨어를 올릴 수 있어요. 케이스 밖에서 누를 수 있게 배치하면 나중에 편합니다.

4×6 기판이 좁으면 LED 회로만 분리

중요. LED 저항 6개는 굳이 메인 기판에 올릴 필요가 없어요. 4×6cm가 빡빡하다 싶으면 LED 저항 6개만 별도의 작은 만능기판(예: 3×7cm 또는 남는 조각)에 납땜하고, 케이스 안 빈 공간에 양면테이프나 글루건으로 고정하세요.

메인 기판과 LED 기판 사이엔 선 7가닥만 건너가면 됩니다: GPIO 6개(GP4 · GP5 · GP6 · GP7 · GP8 · GP9) + GND.

4극 잭 단자 찾기

어느 단자가 T/R1/R2/S인지는 제품마다 달라요. 3극 케이블을 꽂은 뒤 멀티미터 통전 모드로 플러그 반대편의 팁·링·슬리브와 각 단자를 맞춰 보세요. 이때 슬리브와 함께 울리는 단자가 두 개 나오는데, 금속 몸통과 이어진 쪽이 S, 나머지가 R2입니다.

PJ-320A 브레이크아웃은 보통 실크에 T/R1/R2/S 또는 1~4번이 찍혀 있어요.

슬라이더

양 끝 핀을 VCC(3.3V)와 GND에, 가운데 핀을 029에. 방향이 반대면 양 끝을 바꿔 꽂거나 코드의 MOUSE_INVERT_X를 바꾸면 됩니다. RAW가 아니라 VCC에 연결해야 ADC 범위가 맞아요.
